# SillyDroid 点读词典 v0.4.1

适配目标：SillyDroid 1.0.1.68 / SillyTavern 1.19.0。

## 本版修复

- 恢复安卓原生文本选择、长按复制菜单。**不再用 user-select:none 禁止原生选择**。
- 点击英文单词不再靠 `caretPositionFromPoint` 猜坐标，而是把聊天正文中的英文词汇做成轻量可点击的文字片段；原文显示、格式保持不变。
- 只对聊天正文生效。输入框、链接、代码块、快捷回复按钮不改动。
- 默认点读开启；轻点普通英文单词弹出词典并查询。点读关闭后仍可以使用原生选词。
- 新消息出现或滚动到较早消息时，会在当前可见的聊天正文中逐步增加点读交互。
- 无常驻悬浮按钮。魔法棒菜单里有「点读词典」作为备用手动入口。
- 词组、整句、句式、朗读与本机生词本继续保留；查询调用当前配置的模型，并可能产生 API 费用。

## 安装

Git URL: `https://github.com/feixiangdao/test1`
分支: `sillydroid-selection-dictionary`

先在扩展管理中更新该插件，必要时卸载**仅此插件**并重新安装，最后刷新酒馆。

## 测试

1. 进入 Lyra 聊天，轻点英文 `mysterious`，应该弹出「点读英语词典 v0.4.1」。
2. 关闭词典后，长按同一个单词，应该仍能看到安卓的复制/选择菜单。
3. 若轻点仍无反应，请在扩展管理里确认显示「点读 v0.4.1」，并测试魔法棒菜单手动打开词典。

## 已知限制

在真实安卓 WebView 上的行为仍需实机验证。改写聊天正文中普通文本节点的 DOM 可能与少数依赖原始 DOM 结构的扩展冲突。插件仅对可见的消息做处理，滑动到旧消息可能要稍等；系统长按原生菜单保留为回退方案。
